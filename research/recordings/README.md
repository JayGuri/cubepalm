# Recordings of real hands

Put files downloaded from the `/record` page here, then run `npm run research`.
The recognition study scores every reader on them and adds a section to
`docs/research/sign-recognition.md`.

Recordings hold landmark coordinates only, never pictures. They are still
other people's data: keep them out of the public repository unless the person
who made one has said it may be shared. This folder ignores `*.json` for that
reason.
